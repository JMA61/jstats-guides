How-Tos

These how-tos assume you’ve worked through Get Started — you’ll be comfortable loading jstats, using juse() and jload(), and running the basic functions. Each one stands on its own, so read whichever you need; for now, Get Started is the place to begin.

The articles below are on the way. They go beyond the Get Started on-ramp and point toward the fuller treatment in the books.

Regression with categorical predictors

Coming soon — linear and logistic regression with jlm() and jlogistic(). jdummy() is the quick way in for a categorical variable: register its dummy coding and reference category once, and it goes into a model by name — no building dummy variables by hand, and no converting to base R’s factors.
